Thư viện bài (.md)

Lưu mọi bài .md của thầy ở một chỗ: tải lên nhiều file cùng lúc (hoặc kéo thả vào đây), tìm theo lớp – loại bài – từ khoá, mở ra soạn hoặc chiếu ngay. Đồng bộ được với Google Sheets (dùng chung bảng với SmartLesson MD Pro).

Chưa nối Google Sheets
Thả file .md / .json vào đây để thêm vào thư viện
⚙ Kết nối Google Sheets (tuỳ chọn)
  1. Mở Google Sheets mới (sheets.new) → Tiện ích mở rộng → Apps Script.
  2. Xoá mã mặc định, dán mã bên dưới (nút Sao chép mã), bấm Lưu.
  3. Triển khai → Tùy chọn triển khai mới → Ứng dụng web, “Ai có quyền truy cập”: Bất kỳ ai.
  4. Dán đường dẫn Web App vào ô trên, bấm Lưu kết nối. Bảng đang dùng với SmartLesson MD Pro thì dán đúng đường dẫn cũ.
